# 🇫🇷 Version française

## Nom du module

**NS INFO – Framework indispensable aux modules NS INFO**

## Description courte

Le socle commun de tous les modules Dolibarr NS INFO : bibliothèque de fonctions, pages de réglages, onglets
ChangeLog et À propos, bibliothèque de médias. À installer en premier, avant tout module NS INFO.

## Description longue

### Le socle de tous les modules NS INFO

Chaque module NS INFO s'appuie sur un même framework. Plutôt que d'embarquer les mêmes fonctions dans chaque
module, **NS INFO** les regroupe dans un module unique : vos modules NS INFO restent plus légers, plus fiables
et se présentent tous de la même façon.

Le framework ne crée ni menu, ni permission, ni document : il travaille en arrière-plan pour les autres modules.

### Des réglages simples et homogènes

- Une **même page de réglages** pour tous les modules NS INFO, avec des options regroupées en blocs.
- **Interrupteurs oui / non** enregistrés en un clic, champs texte, listes et **sélecteurs de couleur**.
- Bouton **« Valeur par défaut »** pour revenir au réglage d'origine d'une option.
- Interrupteur **« Tout activer / tout désactiver »** pour un groupe d'options.

### Toujours informé

- Onglet **ChangeLog** dans chaque module : les nouveautés et corrections, version par version.
- Onglet **À propos** : documentation, modules NS INFO sur Dolistore et accès direct au **support**.
- La demande de support est **pré-remplie** avec les versions du module, du framework et de Dolibarr.

### Des composants prêts à l'emploi

- **Bibliothèque de médias** : ajout de photos depuis l'ordinateur, la galerie du téléphone ou de la tablette,
  ou depuis la bibliothèque, recherche, détachement et suppression de fichiers.
- Fenêtres et indicateurs de chargement communs aux modules.

### Quelques réglages utiles pour tout Dolibarr

- **Badges de statut colorés et homogènes** (brouillon, validé, payé…) dans les listes et les fiches.
- **Liste des modules plus rapide** : désactivation de la recherche automatique sur Internet de la dernière
  version des modules externes.
- Affichage de la **version** du framework dans les onglets des modules NS INFO.

## Points forts

- ✅ Indispensable à tous les modules NS INFO
- ✅ Réglages homogènes d'un module à l'autre
- ✅ Historique des versions et support accessibles depuis chaque module
- ✅ Bibliothèque de médias partagée
- ✅ Aucun menu, aucune permission à gérer
- ✅ Sans modification du Core

## Compatibilité

- Dolibarr **11.0 et supérieur** (testé sur Dolibarr 22.0)
- PHP **5.5 et supérieur** (testé en PHP 7.4)
- À installer et activer **avant** les autres modules NS INFO ; chaque module NS INFO indique la version
  minimale du framework dont il a besoin
- Langues : français, anglais

ChangeLog, support, bibliothèque de médias, photos, badges de statut, statuts

# 🇬🇧 English version

## Module name

**NS INFO – Required framework for NS INFO modules**

## Short description

The common foundation of all NS INFO Dolibarr modules: function library, setup pages, ChangeLog and About tabs,
media library. Install it first, before any NS INFO module.

## Long description

### The foundation of every NS INFO module

Every NS INFO module relies on the same framework. Instead of shipping the same functions in each module,
**NS INFO** gathers them in a single module: your NS INFO modules stay lighter, more reliable, and all look
and work the same way.

The framework creates no menu, no permission and no document: it works in the background for the other modules.

### Simple and consistent settings

- The **same setup page** for all NS INFO modules, with options grouped in blocks.
- **Yes / no switches** saved in one click, text fields, lists and **color pickers**.
- **"Default value"** button to restore an option to its original setting.
- **"Enable all / disable all"** switch for a group of options.

### Always informed

- **ChangeLog** tab in each module: new features and fixes, version by version.
- **About** tab: documentation, NS INFO modules on Dolistore and direct access to **support**.
- Support requests are **pre-filled** with the versions of the module, the framework and Dolibarr.

### Ready-to-use components

- **Media library**: add photos from the computer, the phone or tablet gallery, or from the library; search,
  unlink and delete files.
- Dialogs and loading indicators shared by the modules.

### A few useful settings for the whole of Dolibarr

- **Colored, consistent status badges** (draft, validated, paid…) in lists and cards.
- **Faster module list**: disables the automatic online check for the latest version of external modules.
- Display of the framework **version** in the tabs of NS INFO modules.

## Highlights

- ✅ Required by all NS INFO modules
- ✅ Consistent settings from one module to another
- ✅ Version history and support available from every module
- ✅ Shared media library
- ✅ No menu, no permission to manage
- ✅ No change to the Dolibarr core

## Compatibility

- Dolibarr **11.0 and higher** (tested on Dolibarr 22.0)
- PHP **5.5 and higher** (tested with PHP 7.4)
- Install and enable it **before** the other NS INFO modules; each NS INFO module states the minimum framework
  version it needs
- Languages: French, English
